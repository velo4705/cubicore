The real commandsNot fiction
This runs inside your coding agent.
Cubicore is an MCP — it plans, briefs, gates and records. The host dispatches the sub-agents; this tutorial shows what the host sees and what actually happens.
/cubicore:plan-demo
Decompose the request into disjoint contracts with checks, before any money is spent.
/cubicore:execute
Dispatch all associates in parallel; collect artifacts; run an integration pass.
/cubicore:debug
Find broken code, loose imports, dead state; fix and re-check until green.
/cubicore:preview
Serve the delivered app on localhost and leave it running to be opened.
/cubicore:continue
After any interruption: reconcile disk checks, resume only unfinished contracts.
/cubicore:refine
Add or change one feature; re-run only the affected contracts.
