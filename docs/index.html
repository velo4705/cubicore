A factory that refuses bad work.

01

Team or solo, decided by evidence

Cubicore sizes the task by contracts, dependency edges and write scopes. One agent when that is enough, a team when the slices are independent.

02

Checks, not opinions

Each contract carries blocking checks: tests, typecheck, grep. Done means those checks passed on disk.

03

You approve the team, not the code

Factory fit is one question: team of N, or a single agent. No transcripts to read.

04

Collisions are caught, not blamed

Cubicore checks scopes at plan time, then checks files that landed outside the plan.

05

A finished worktree, not a promise

Checks re-run on the real tree before done. The ledger records tokens, cost and the verdict.

06

It says when it refuses

Coupled, ambiguous or empty tasks get refused or a single agent. The refusal goes into the plan.

Inside OpenCode, from any git repo. Cubicore is an MCP, a parallel factory with contracts, not another chatbot wrapper.

One command, inside OpenCode.

Global install for Linux, macOS, Windows and NixOS. Native OpenCode uses your config. Flatpak needs --flatpak.

npx cubicore@latest setup
  1. 1

    The installer detects OpenCode, backs up your config and wires the MCP.

  2. 2

    Restart OpenCode. The /cubicore:* commands appear.

  3. 3

    Run /cubicore:plan-demo "...". Cubicore writes CUBICORE_PLAN.md and asks the factory-fit question.

  4. 4

    Review the plan. Say /cubicore:execute when satisfied.
