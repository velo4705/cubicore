Features

Not a swarm. A factory that refuses bad work.

factory-fit

Team or solo, decided by evidence

Before anything dispatches, Cubicore sizes the task: contracts, dependency edges, write scopes. One agent if that's enough. A team if the slices are truly independent. Never maximum, never guesswork.

mechanical gates

Checks, not opinions

Every contract ships with blocking checks (tests, typecheck, grep). The run doesn't hit “done” until the checks actually pass on disk.

founder-facing

You approve the team, not the code

Factory-fit arrives as a question you answer with one click: team of N, or single agent? No transcripts required.

union-scope

Collisions are caught, not blamed

Write-scope disjointness is checked at plan time; the run also checks that nothing landed outside the plan's declared files.

verified on disk

A finished worktree, not a promise

Work only reaches done after blocking checks re-ran on the real tree. The ledger records tokens, cost, and the factory's own verdict.

honest by default

It says when it refuses

Coupled, ambiguous, or empty tasks get refused — or a single agent — not a fake fan-out. The refusal is recorded in the plan, not hand-waved away.

Install

One command. No ceremony.

$ npx cubicore@latest setup
✓ mcp registered in opencode.json
✓ agents installed
$ restart opencode
$ /cubicore:plan-demo

Global install, Linux/macOS/Windows/NixOS. Native OpenCode (existing config) by default; Flatpak requires --flatpak.

1

Run the installer. It detects OpenCode, backs up your config, wires the MCP.

2

Restart OpenCode. The /cubicore:* commands appear automatically.

3

/cubicore:plan-demo "…" — Cubicore writes CUBICORE_PLAN.md and asks the founder the factory-fit question.

4

Review the plan. Say /cubicore:execute when satisfied.
