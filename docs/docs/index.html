What it is

A prompt becomes a delivered system.

Cubicore turns a prompt into a plan, splits it into independent contracts, runs them in parallel with worktree isolation, gates every contract with mechanical checks, and iterates until the preview block passes, then debugs review/test/fix until the remaining issues disappear.

You get: parallel execution, mechanical verification, contract-driven scope, automatic fix loops.

Features

Built for parallel, verified delivery.

Parallel by Default

Contracts with disjoint write scopes run simultaneously. No manual orchestration.

Mechanical Verification

Every contract has blocking, convergent checks (tests, typecheck, lint). No “looks good” — only pass/fail.

Contract-Driven Scope

Each worker gets its own write scope, read list, and checks. Collisions caught at plan time, not runtime.

Auto-Debug Loop

Checks fail → /cubicore:debug reviews/tests/fixes → re-tests → loops until the failures disappear.

Three commands, no ceremony.

# 2. Plan
cubicore plan "Build a personal expense tracker API with SQLite"

# 3. Execute
cubicore execute

How it works

From prompt to product in five steps.

Plan

/cubicore:plan-demo/plan-full researches the repo, asks clarifying questions, writes CUBICORE_PLAN.json, and checks a preview block.

Design

Cubicore writes one brief per associate into CUBICORE_ASSOCIATES/, with its own scope, checks, and no cross-reads.

Execute

Spawns isolated associates in parallel, gating each with Schema → Verify → Scope.

Debug

Reviews code and runs all contract checks. Failures become minimal fixes and re-runs until green.

Deploy

/cubicore:deploy plans hosting, writes the deploy handoff, and serves a clean production result.

Commands Reference

The core interface.

Command Purpose Typical Output
cubicore plan Create a plan, contracts, and validation map. CUBICORE_PLAN.json, contract briefs, preview block
cubicore execute Run the queued contracts in parallel with isolated scopes. Per-associate logs, verification results, status summary
cubicore debug Inspect failed checks and repair the root cause. Fix suggestions, patch loop, re-check confirmation
cubicore deploy Prepare the production handoff and deployment plan. Serve readiness, deployment notes, handoff artifact
